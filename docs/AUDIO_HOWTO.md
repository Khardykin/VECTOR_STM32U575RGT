# Как запускать звук

Это главный документ по управлению плеером. Архитектура и контексты —
`CODE_MAP.md`, память и образ — `AUDIO_MAP.md` / `FLASH_PROGRAMMING.md`,
история правок — `FIX_REPORT.md`.

---

## 0. Быстрый старт: услышать звук через минуту

В `Core/VectorLib/Inc/vector_config.h` уже стоят нужные значения:

```c
#define VECTOR_AUDIO_BOOT_PLAY      1     /* при старте войти в состояние 0 */
#define VECTOR_AUDIO_LOOP_STATE     1     /* звук состояния - по кругу      */
#define VECTOR_AUDIO_LOOP_PAUSE_MS  500u  /* пауза между повторами          */
```

Прошиваете → включаете → **сразу слышите `a_gas` (1.85 с), пауза 0.5 с, снова
`a_gas`** и так по кругу, пока не остановите. В логе при этом:

```
[0.31] 2/A: audio init
[0.39] 2/A: image ok=1 sounds=4
[0.40] 2/A: boot: state 0, sound #0, loop=1 pause=500 ms
[0.45] 2/F: read 29536 b @0x1a8 ok, 12 ms
[0.46] 2/A: play #0 'a_gas' 14768 samples @8000 Hz
[2.32] 1/A: sound finished (всего доиграно 1)
[2.83] 2/A: play #0 'a_gas' ...          <- повтор цикла
```

Если звука нет — раздел 7 («Порядок проверки»), там же что означает каждая
переменная. Если в `start_now()` не срабатывает точка останова — раздел 7.1,
это почти всегда `VECTOR_AUDIO_BOOT_PLAY = 3` (тогда при старте играет
`beep_now()`, а не `start_now()`) или команды просто не доходят до потока.

## 1. Модель: состояние → звук → цикл

Плеер живёт в одном из **состояний** (`ap_state = 0..2`). Состоянию назначен
звук таблицей `ap_state_map[]` в `audio_player.c`:

| состояние | звук | что происходит |
|---|---|---|
| 0 | `SND_STATE_DEFAULT_0` = `a_gas` (idx 0, 1.85 с) | играет, при цикле — по кругу |
| 1 | `SND_STATE_DEFAULT_1` = `b_click` (idx 1, 0.06 с) | играет, при цикле — по кругу |
| 2 | `AUDIO_STATE_SILENT` = 0xFFFF | **тишина** — «пустая ячейка» таблицы |

Это и есть то, что вы формулировали как «сделаем пустой массив»: состояние без
звука (`AUDIO_STATE_SILENT`) = тишина, цикл по нему не взводится.

```
audio_set_state(0)  ──►  ap_state = 0
                          ap_state_map[0] = a_gas
                          │
                          ▼
                    start_now(a_gas)  ── ext_read из внешней flash ──► ap_buf[]
                          │                                            + громкость
                          ▼
                    HAL_SAI_Transmit_DMA ──► I2S ──► усилитель ──► динамик
                          │
              (звук доиграл, GPDMA1_Channel11 → ISR → семафор)
                          ▼
                    пауза 500 мс  ──►  start_now(a_gas)  ──► ... по кругу
```

Одноразовый `audio_play()` встраивается в эту схему: звучит **вместо**
очередного повтора, после чего цикл продолжается.

---

## 2. API

Все функции можно звать **из потока и из ISR**: они только кладут команду в
очередь ThreadX и взводят семафор. Работу делает один поток `Audio Player`.

| Функция | Что делает | Возврат |
|---|---|---|
| `audio_set_state(st)` | **смена режима**: текущий звук прерывается, играется звук состояния `st` (0..2), при `VECTOR_AUDIO_LOOP_STATE=1` — по кругу. `st = 2` = тишина | — |
| `audio_play(id)` | одноразовый звук в очередь: доиграет текущий, затем сыграет `id`; если свободно — сразу | `audio_err_t` |
| `audio_play_name("a_gas")` | то же, поиск по имени в таблице образа | `audio_err_t` |
| `audio_stop()` | **полный стоп**: гасит звук, чистит очередь, отложенный звук и цикл | — |
| `audio_beep()` | аварийный писк из внутренней flash (не зависит от внешней памяти) | — |
| `audio_set_loop(1/0)` | включить/снять цикл (текущий повтор доиграет) | — |
| `audio_set_loop_pause(ms)` | пауза между повторами, применяется со следующего | — |
| `audio_set_volume(0..100)` | громкость; применяется при следующем старте звука | — |
| `audio_get_state()` / `audio_get_loop()` / `audio_get_volume()` / `audio_get_loop_pause()` | прочитать текущие значения | — |
| `audio_count()` / `audio_name(i)` / `audio_image_ok()` / `audio_reload_image()` | справка по образу | — |

`id` — индекс звука из `audio_ids.h` (генерируется вместе с образом):
`SND_A_GAS = 0`, `SND_B_CLICK = 1`, `SND_C_VOICE_GAS = 2`, `SND_D_MYVOICE = 3`.

Коды `audio_err_t`: `0` OK, `1` нет образа, `2` неверный индекс, `3` звук
длиннее буфера, `4` ошибка чтения flash или запуска DMA, `5` очередь полна.

## 3. Как остановить

Три способа, по убыванию «жёсткости»:

| Вызов | Эффект |
|---|---|
| `audio_stop()` | **всё**: звук обрывается, очередь и отложенный звук чистятся, **цикл снимается**. Тишина до следующей команды |
| `audio_set_state(2)` | переход в состояние «тишина»: звук обрывается, цикл не взводится (состояние запоминается — `audio_get_state()` вернёт 2) |
| `audio_set_loop(0)` | цикл снимается, но **текущий** повтор доигрывает до конца, дальше тишина |

Кнопкой в тестовом режиме: `BUTTON3` = `audio_stop()`, `BUTTON1` до состояния 2
= тишина.

Снова включить: `audio_set_state(0)` (или другое состояние со звуком) — цикл
взводится заново, если `audio_get_loop()` = 1.

## 4. Значения по умолчанию

| Что | Значение | Где менять |
|---|---|---|
| `ap_state` | `0` | задаётся только через `audio_set_state()` |
| звук состояния 0 | `SND_A_GAS` | `ap_state_map[]` в `audio_player.c` |
| звук состояния 1 | `SND_B_CLICK` | то же |
| звук состояния 2 | тишина | то же |
| цикл | **включён** | `VECTOR_AUDIO_LOOP_STATE` / `audio_set_loop()` |
| пауза цикла | 500 мс | `VECTOR_AUDIO_LOOP_PAUSE_MS` / `audio_set_loop_pause()` |
| громкость | 100 % | `audio_set_volume()` |
| действие при старте | войти в состояние 0 (и запустить цикл) | `VECTOR_AUDIO_BOOT_PLAY`: 0 ничего, 1 состояние 0, 2 звук #0 один раз, 3 аварийный писк |
| очередь команд | 8 | `AUDIO_QUEUE_LEN` |
| слот ожидания `audio_play` | **один** (последний вытесняет предыдущий, `audio_dbg_dropped`) | — |

## 5. Кнопки (тестовый режим `VECTOR_AUDIO_DEMO_KEYS = 1`)

| Кнопка | Пин | Действие |
|---|---|---|
| BUTTON1 | PB1 | цикл состояний `0 → 1 → 2 → 0`, звук нового состояния стартует сразу |
| BUTTON2 | PB2 | следующий звук образа по кругу (`audio_play`) |
| BUTTON3 | PB3 | `audio_stop()` |

Пиновская конфигурация — из CubeMX (`gpio.c`: `GPIO_MODE_IT_RISING_FALLING` +
`GPIO_PULLUP`). Активный уровень должен ей соответствовать:
`VECTOR_KEY_PRESSED_LEVEL = 0` при pull-up (кнопка замыкает пин на GND). Если
перепутать, звук будет стартовать по **отпусканию** кнопки.

## 6. Пример: как это использовать в рабочем коде

```c
#include "audio_player.h"

/* Поток обработки газа */
void gas_thread_entry(ULONG arg)
{
  (void)arg;
  for (;;)
  {
    gas_result_t r = gas_read();            /* ваш датчик */

    if (r.level >= GAS_ALARM)
    {
      /* ТРЕВОГА: один вызов - и звук идёт по кругу, пока не снимем.
         Держать таймеры/циклы в своём коде не нужно. */
      if (audio_get_state() != 0) { audio_set_state(0); }      /* a_gas */
      audio_play(SND_C_VOICE_GAS);            /* голосовая подсказка поверх цикла */
    }
    else if (r.level >= GAS_WARN)
    {
      if (audio_get_state() != 1) { audio_set_state(1); }      /* b_click */
    }
    else
    {
      if (audio_get_state() != 2) { audio_set_state(2); }      /* ТИШИНА */
    }

    tx_thread_sleep(100);                   /* 1 с: тик ThreadX = 10 мс */
  }
}
```

Правило, которое стоит соблюдать: **не дёргать `audio_set_state()` каждый
цикл**, а только при смене уровня — иначе звук будет обрываться и начинаться
заново (смена состояния прерывает текущий). `audio_get_state()` для этого и
отдан наружу.

## 7. Порядок проверки, если звука нет

### 7.1 Точка останова в `start_now()` не срабатывает

`start_now()` вызывается только из потока `Audio Player` и только по команде.
Проверьте по порядку:

1. `VECTOR_AUDIO_BOOT_PLAY` — если `3`, при старте вызывается `beep_now()`, а
   не `start_now()`. Поставьте `1` (по умолчанию так и есть).
2. `audio_dbg_boot_stage` — должно быть `5` (рабочий цикл). `2`/`4` = во
   внешней flash нет валидного образа, тогда вместо звука будет писк.
3. `demo_dbg_edges` / `demo_dbg_press` — доходят ли кнопки (см. таблицу в
   `audio_demo.h`). `press = 0` при растущем `edges` = не совпал активный
   уровень с подтяжкой.
4. `audio_dbg_keys` / `audio_dbg_last_cmd` — дошла ли команда до потока
   (`3` = state, `1` = play, `2` = stop, `4` = beep).
5. `audio_dbg_wakes` растёт, `audio_dbg_timeouts` растёт — поток жив, просто
   событий нет (это нормальное состояние ожидания, а не зависание).

### 7.2 Команда доходит, звука нет

| Симптом | Причина |
|---|---|
| `audio_dbg_started` не растёт | `start_now()` вернул ошибку: `audio_dbg_last_err` (`1` нет образа, `2` индекс, `3` длинный звук, `4` DMA/flash) |
| `started` растёт, `played` нет | не пришёл колбэк завершения SAI-DMA: `GPDMA1_Channel11_IRQn`, а `audio_dbg_stuck > 0` значит звук добил watchdog |
| всё растёт, тишина | `SD_MODE` (PC9) = 0 → усилитель в shutdown; или `audio_get_volume()` = 0 |
| лог `flash probe FAIL` / `jedec` не `c2 ?? 17` | внешняя flash не отвечает: SPI1, CS PA4, питание |
| `factory: done ... verified` и сразу `image ok=0` | было: `load_image()` перезатирал заголовок таблицей, CRC не сходился никогда — исправлено; если повторится, в логе будет конкретная причина (`image header bad:` / `image CRC mismatch:`) |
| `beep DMA fail: hal=2` | SAI занята предыдущей передачей (`HAL_BUSY`): не был вызван `HAL_SAI_Abort` |
| `play #...` в логе есть, `audio_dbg_played` растёт, а звука нет | тракт аналоговый: `SD_MODE` (PC9) = 1? усилитель запитан? I2S-пины PA8/PA9/PA10 (AF13)? PLL3 запущен? |
| `sf_dbg_dma_fallback` растёт | чтение ушло в опрос (данные целы, просто медленнее): смотрите `sf_dbg_dma_tmo`, включён ли `SPI1_IRQn` |

### 7.3 Цикл не повторяется

* `audio_get_loop()` = 0 → `audio_set_loop(1)` или `VECTOR_AUDIO_LOOP_STATE 1`;
* `audio_dbg_loops` не растёт, хотя звук доиграл → `ap_loop_idx = -1`: состояние
  «тишина» (2) или был вызван `audio_stop()` (он снимает цикл);
* повтор идёт без паузы → `audio_set_loop_pause(500)`.

## 8. Ограничения схемы

* Один звук ≤ 65535 сэмплов = **8.19 с** при 8 кГц: звук читается **целиком** в
  `ap_buf[65535]` (131 070 Б) и уходит в SAI одной DMA-транзакцией.
* Одновременно звучит только один звук: буфер один.
* Частота фиксирована SAI: 8 кГц, I2S, 16 бит, моно.
* Пауза цикла выдерживается с точностью тика ThreadX (10 мс) плюс время чтения
  звука из flash (десятки мс для коротких, до ~50 мс для 128 КБ).
* Длинные записи (минуты) = стриминг с circular DMA и подкачкой половин буфера;
  это следующий этап, см. `FIX_REPORT.md`, раздел 9.

## 9. Как поменять набор звуков

```
tools/pack_sounds.py  ваши.wav ...  ->  build/sounds.img + audio_ids.h
tools/bin2c.py        sounds.img    ->  audio_factory_image.c (const в прошивке)
```

Если нужно, чтобы устройство **никогда** само не писало внешнюю flash,
поставьте `VECTOR_AUDIO_FACTORY_ON_BOOT 0`: тогда при невалидном образе плеер
играет аварийный писк и печатает причину, а образ пишется внешним
программатором или вашим вызовом `audio_factory_program()`.

`audio_ids.h` перегенерируется вместе с образом, поэтому `SND_*` и
`SND_STATE_DEFAULT_0/1` обновятся сами. Привязку состояний к звукам правите в
`ap_state_map[]` (есть проверка на этапе компиляции: несуществующий индекс не
соберётся). При старте прошивка сравнит образ во внешней flash и, если его нет
или он битый, запишет встроенный — factory-режим (`VECTOR_AUDIO_FACTORY_EMBED`).
Подробно — `FLASH_PROGRAMMING.md` и `SCRIPT_PRACTICE.md`.
