## Быстрый старт

1. **Собрать**: STM32CubeIDE, проект `VECTOR_STM32U575RGT`, конфигурация Debug.
   HAL, CMSIS и Middlewares (ThreadX) подтягиваются из репозитория CubeMX — в
   git их нет (`.gitignore`).
2. **Терминал**: UART4 (PC10), 115200 8N1 — туда идёт лог (`VECTOR_LOG_UART 4`).
   Альтернатива — консоль внутри CubeIDE через SWO (`VECTOR_LOG_ITM 1`), но
   только если освободить PB3 (сейчас там BUTTON3, а PB3 = JTDO/TRACESWO).
   Текст сообщений — латиница: терминал в CP1251 показывает кириллицу
   кракозябрами.
3. **Прошить и включить**: сначала три писка (`audio_selftest`, прямо из
   `main()`, без RTOS и внешней памяти), затем `poeshl` по кругу с паузой
   500 мс. Это штатная проверка всего тракта.
4. **Управлять** из кода: `audio_set_state(0/1/2)`, `audio_play(SND_*)`,
   `audio_stop()`. В тестовом режиме то же самое на кнопках PB1/PB2/PB3.
5. **Диагностика**: строки лога `tick ...` / `irq load: ...` и переменные
   `audio_dbg_*`, `sf_dbg_*`, `demo_dbg_*`, `ub_*`, `sys_dbg_*` в Expressions.
   Расшифровка — `AUDIO.md` раздел 6 и `SYSTEM.md` разделы 5, 7.

## Все переключатели (`Core/VectorLib/Inc/vector_config.h`)

### Звук

| Макрос | По умолчанию | Смысл |
|---|---|---|
| `VECTOR_AUDIO_SELFTEST` | `3` | число писков при старте из внутренней flash, без RTOS (`0` = не проверять) |
| `VECTOR_AUDIO_BOOT_PLAY` | `1` | что сделать при старте: `0` ничего, `1` войти в состояние 0 (цикл), `2` звук #0 один раз, `3` только писк |
| `VECTOR_AUDIO_LOOP_STATE` | `1` | звук состояния повторяется по кругу с паузой |
| `VECTOR_AUDIO_LOOP_PAUSE_MS` | `500` | пауза между повторами |
| `VECTOR_AUDIO_FACTORY_EMBED` | `1` | линковать образ (192.8 КБ) во внутреннюю flash |
| `VECTOR_AUDIO_FACTORY_ON_BOOT` | `1` | `0` = прошивка внешнюю flash на старте **не трогает вообще** |
| `VECTOR_AUDIO_DEMO_KEYS` | `1` | `0` = кнопки отдаются рабочему коду, демо-модуль исчезает |
| `VECTOR_KEY_PRESSED_LEVEL` | `0` | активный уровень кнопки (при `GPIO_PULLUP` в кубе — 0) |
| `VECTOR_KEY_DEBOUNCE_MS` | `50` | антидребезг, свой отсчёт на каждую кнопку |
| `VECTOR_AUDIO_WAKE_TIMEOUT_MS` | `1000` | heartbeat потока плеера (`0` = ждать вечно) |

Частота дискретизации — `AUDIO_SAMPLE_RATE` в `audio_player.h` (16000), должна
совпадать с SAI1 в CubeMX и с `--rate` сборки образа.

### Лог

| Макрос | По умолчанию | Смысл |
|---|---|---|
| `VECTOR_LOG_ENABLE` | `1` | `0` = лог вырезается из прошивки целиком (ни кода, ни строк) |
| `VECTOR_LOG_ITM` | `1` | вывод в ITM/SWO → консоль CubeIDE (нужен свободный PB3) |
| `VECTOR_LOG_UART` | `4` | вывод в UART: `0` выкл, `1/2/3/4` = USART1/2/3/UART4 |
| `VECTOR_LOG_LEVEL` | `2` | порог: 1 DEBUG, 2 INFO, 3 WARN, 4 ERROR (рантайм: `vlog_set_level`) |
| `VECTOR_LOG_MASK` | `0xFFFFFFFF` | какие модули печатать (рантайм: `vlog_set_mask`) |
| `VECTOR_LOG_TICK_REPORT_S` | `10` | период отчёта о системном времени (`0` = выключить) |

### Прочее

| Макрос | По умолчанию | Смысл |
|---|---|---|
| `VECTOR_SPI_DMA` | `1` | большие чтения внешней flash по DMA (с автооткатом на опрос) |
| `VECTOR_SPI_DMA_MIN_LEN` / `_CHUNK` / `_TMO_MS` | `1024` / `32768` / `250` | порог, размер куска, таймаут куска |
| `VECTOR_UART_BRIDGE_TEST` | `1` | `0` = мост выключен, UART свободны |
| `VECTOR_UB_RING` | `256` | глубина колец моста |
| `VECTOR_DBG_FREEZE_TICK` | `1` | замораживать тайм-базу HAL, пока ядро стоит под отладчиком |

## Время и таймеры

| Чем | Разрешение | Когда |
|---|---|---|
| `VTICK_MS()` / `VTICK_ELAPSED_MS()` | 10 мс | **единственный** способ читать время в VectorLib (тик RTOS, SysTick) |
| `VTICK_SLEEP_MS()` | 10 мс | сон потока (`tx_thread_sleep`, CPU не грузит) |
| `VTICK_MS2TICKS()` | — | мс → тики для `tx_semaphore_get` |
| число проходов цикла | — | ограничение времени **до планировщика**, где тика RTOS нет (`wait_busy`, `audio_selftest`) |
| `HAL_GetTick()` | 1 мс | **в нашем коде не используется**; остался только внутри HAL-драйверов и как измеряемая величина в приборах |
| аппаратный таймер (PWM/OC) | такты | ровный сигнал без ISR |
| RTC | 1 с | долгое время, метки событий (CK_SPRE = 1 Гц) |

Подробно, включая «почему мигалка в тике не даёт ровный меандр» и разбор цифр из
лога — `SYSTEM.md`, раздел 7.

## Правила правки кода

* Файлы `Core/Src/*.c` и `AZURE_RTOS/App/*` генерирует CubeMX — правки только
  внутри `/* USER CODE BEGIN ... */`, иначе потеряются при перегенерации.
  Конфигурация периферии — **только в CubeMX** (список: `SYSTEM.md` раздел 9).
* Весь наш код — в `Core/VectorLib/**`. Переключатели — только в
  `vector_config.h`, не размазывать по модулям.
* Из ISR допустимы только неблокирующие вызовы: `tx_queue_send(TX_NO_WAIT)`,
  `tx_semaphore_put`, флаги и счётчики. Лог из ISR отбрасывается.
* Время — только через `vector_tick.h` (`VTICK_*`), `HAL_GetTick`/`HAL_Delay` в
  модули не тащить.
* У каждой функции — комментарий: что делает, в каком контексте
  (init / поток / ISR), что возвращает.
* Строки лога — только ASCII (латиница), иначе в терминале CP1251 кракозябры.
