## Быстрый старт

1. **Собрать**: STM32CubeIDE, проект `VECTOR_STM32U575RGT`, конфигурация Debug.
   HAL, CMSIS и Middlewares (ThreadX) подтягиваются из репозитория CubeMX — в
   git их нет (`.gitignore`).
2. **Подключить терминал** к UART4 (PC10), 115200 8N1 — туда идёт лог
   (`VECTOR_LOG_UART 4`). Альтернатива: консоль внутри CubeIDE через SWO
   (`VECTOR_LOG_ITM 1`), но только если PB3 свободен — сейчас там BUTTON3.
   Текст сообщений — латиница: терминал в CP1251 показывает кириллицу
   кракозябрами (либо переключите терминал в UTF-8).
3. **Прошить и включить**: при `VECTOR_AUDIO_BOOT_PLAY 1` сразу заиграет
   `a_gas` по кругу с паузой 500 мс. Это штатная проверка всего тракта:
   внешняя flash → чтение → SAI/DMA → усилитель.
4. **Управлять** из кода: `audio_set_state(0/1/2)`, `audio_play(SND_*)`,
   `audio_stop()`. В тестовом режиме те же действия на кнопках PB1/PB2/PB3.
5. **Диагностика**: переменные `audio_dbg_*`, `sf_dbg_*`, `demo_dbg_*`, `ub_*`,
   `sys_dbg_ticks` в Expressions / Live Expressions. Расшифровка —
   AUDIO_HOWTO.md раздел 7 и CODE_MAP.md раздел 5.

## Главные выключатели (`Core/VectorLib/Inc/vector_config.h`)

| Макрос | По умолчанию | Смысл |
|---|---|---|
| `VECTOR_AUDIO_LOOP_STATE` | `1` | звук состояния повторяется по кругу с паузой |
| `VECTOR_AUDIO_LOOP_PAUSE_MS` | `500` | пауза между повторами |
| `VECTOR_AUDIO_BOOT_PLAY` | `1` | что сделать при старте: `0` ничего, `1` войти в состояние 0 (цикл), `2` звук #0 один раз, `3` аварийный писк |
| `VECTOR_LOG_ENABLE` | `1` | `0` = лог вырезается из прошивки целиком |
| `VECTOR_LOG_ITM` / `VECTOR_LOG_UART` | `1` / `4` | каналы вывода лога: SWO-консоль CubeIDE / UART |
| `VECTOR_SPI_DMA` | `1` | большие чтения внешней flash по DMA (с автооткатом на опрос) |
| `VECTOR_AUDIO_DEMO_KEYS` | `1` | `0` = кнопки отдаются рабочему коду, демо-модуль исчезает из сборки |
| `VECTOR_UART_BRIDGE_TEST` | `1` | `0` = мост выключен, UART свободны |
| `VECTOR_AUDIO_FACTORY_EMBED` | `1` | линковать образ (195 КБ) в прошивку |
| `VECTOR_AUDIO_FACTORY_ON_BOOT` | `1` | `0` = прошивка внешнюю flash на старте **не трогает вообще** (образ пишет программатор или ваш вызов `audio_factory_program()`) |
| `VECTOR_KEY_PRESSED_LEVEL` | `0` | активный уровень кнопки (согласовать с подтяжкой в `gpio.c`) |
| `VECTOR_UB_RING` | `256` | глубина колец моста UART |
| `VECTOR_LOG_TICK_REPORT_S` | `10` | период отчёта о системном тике в лог (0 = выключить) |
| `VECTOR_KEY_DEBOUNCE_MS` | `50` | антидребезг кнопок, отдельно на каждую кнопку |
| `VECTOR_AUDIO_WAKE_TIMEOUT_MS` | `1000` | heartbeat потока плеера (`0` = ждать вечно) |

## Измерение времени

| Чем | Разрешение | Когда |
|---|---|---|
| `HAL_GetTick()` | 1 мс | таймауты, грубые интервалы. Зависит от IRQ TIM6 (приоритет 15) |
| `tx_thread_sleep()` | 10 мс | периодика в потоке (тик ThreadX = 100 Гц) |
| `vtime_us()` / `vtime_elapsed_us()` (DWT->CYCCNT) | 6.25 нс | измерить длительность, дрожание, профиль |
| аппаратный таймер (PWM/OC) | такты | ровный сигнал без ISR: TIM2_CH1 уже настроен на PA15 |
| RTC | 1 с | долгое время, сон, метки событий |

Подробно, включая «почему мигалка в тике даёт неровный меандр» —
`CODE_MAP.md`, раздел 7.

## Правила правки кода (коротко)

* Файлы `Core/Src/*.c`, `AZURE_RTOS/App/*` генерирует CubeMX — правки только
  внутри `/* USER CODE BEGIN ... */`, иначе потеряются при перегенерации.
* Весь наш код — в `Core/VectorLib/**`. Переключатели «тест/рабочее» — только в
  `vector_config.h`, не размазывать по модулям.
* Из ISR допустимы только неблокирующие вызовы: `tx_queue_send(TX_NO_WAIT)`,
  `tx_semaphore_put`, флаги и счётчики. Лог из ISR не печатается (отбрасывается).
* Любая новая функция — с комментарием: что делает, в каком контексте
  (init / поток / ISR), что возвращает.
